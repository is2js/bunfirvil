# 분퍼빌 놀이터 일러스트

승인된 2026-10-15 표지의 시각 언어와 정확한 프롬프트를 재사용한다. 같은 분위기를 재현하는 스킬이며 동일한 픽셀이나 특정 seed의 재생을 보장하지 않는다.

## 참고 자료와 기본값

생성 전 [승인 프롬프트·제작 기록](references/approved-generation.v1.json)의 `prompt`를 완전히 읽고 다음 이미지를 직접 확인한다.

- [원래 표지](assets/og.png): 네이비 배경, 민트 광원, 금색 테두리와 좌측 타이포 구성만 참고한다. 옛 영어 문구를 복사하지 않는다.
- [실제 놀이터 화면](assets/og-playground-v2.jpg): 아파트 단면·주방·바닥·창호·캐릭터의 소재 참고용이다. HUD나 금액·버튼을 재현하지 않는다.
- [승인된 새 일러스트](assets/og-playground-v3.jpg): 이번에 사용자가 좋아한 최종 분위기·밝기·한국어 가독성의 기준이다.

기본 문구는 `e편한세상 / 분당퍼스트빌리지 / 돌아온범생의 놀이터`다. 사용자 요청 없이 PVP의 게임명이나 옛 영어 제목으로 바꾸지 않는다.

## 제작

1. 대상 저장소의 지침과 [제작·프로젝트 반영 기준](references/workflow.md)에서 해당 프로젝트 절을 읽는다.
2. 새 일러스트 요청에는 내장 이미지 생성 도구를 사용한다. 도구가 없으면 한계를 알리고 멈춘다. 사용자 동의 없이 CLI/API, 계정 설정 또는 별도 결제 경로로 전환하지 않는다.
3. 원래 결과를 재현하려면 참고 이미지 1·2와 기록된 프롬프트를 그대로 사용한다. 승인 표지에 가까운 변형이면 이미지 3도 결과 스타일 참고로 추가하고, 프롬프트에서 이미지별 역할을 명시한다. 이미지 3에 없는 새 세부 사항은 사용자 요청 범위 안에서만 바꾼다.
4. 내장 도구에서 로컬 참고 경로를 지원하면 실제 경로를 전달하고, 그렇지 않으면 먼저 이미지를 대화에 표시한 뒤 지원하는 참조 방식을 사용한다. 존재하지 않는 도구 인자를 만들지 않는다. 불투명 배경으로 한 장을 만들되 요청한 후보 수가 있으면 따른다.
5. 생성 결과의 한글·구도·밝기를 직접 확인한다. 수정할 때는 바꿀 요소만 지정하고 나머지를 보존한다. 원본 출력은 프로젝트의 새 버전 경로에 보관한다.
6. 웹 미리보기가 필요할 때만 [준비 스크립트](scripts/prepare-link-preview.ps1)로 1200×630 JPEG를 만든다. 이는 리사이즈·중앙 크롭·인코딩 도구이지 생성 도구가 아니다. 변환 후 글자와 창호가 잘리지 않았는지 다시 확인한다.
7. 실제 사용한 프롬프트, 참고 이미지 역할, 원본·변환 파일, 생성 방식과 검수 결과를 남긴다. 새 제작 이력은 새 버전으로 쓰고 이 스킬의 승인 기준 파일을 덮어쓰지 않는다.

## 유지할 시각 기준

- 좌측 약 40%: 크고 선명한 한국어 제목. 우측 약 60%: 밝은 아이보리·나무 바닥의 입체 아파트 단면.
- 거의 검은 네이비 배경, 절제된 민트 건축 그리드와 얇은 금색 장식, 따뜻한 실내 조명.
- 주거 공간이 주인공이며 작은 성인 치비 아바타 2명은 공간에 비해 작게 유지.
- 실제 화면 캡처·실사·측량 평면도가 아닌 형상화한 표지 일러스트.
- HUD, 옵션 금액, 키캡, 미니맵, 과도한 홀로그램, 전투·무기·몬스터, 워터마크, 실제 동호·개인 닉네임은 제외. `돌아온범생의 놀이터`는 승인된 브랜드 문구다.
- 기본 출력은 불투명한 1200×630 링크 표지. 공식 기업 로고나 제휴·공식 평면도의 인상을 임의로 추가하지 않는다.

## 작업 경계

이 스킬은 마케팅·링크 표지용이다. 런타임 맵, 벽·충돌, 옵션 배치, 캐릭터 모션, 생성 snapshot을 바꾸지 않는다. 결과 저장과 기존 표지 교체·커밋·푸시·운영 배포는 구분하며, 현재 사용자가 승인한 범위와 대상 저장소 규칙을 따른다. 기본적으로 기존 파일을 보존하고 새 버전 후보를 만든다.
